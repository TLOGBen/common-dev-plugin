# Military Doctrine Mapping

Use this reference only as a conceptual and engineering mapping. The cited material is data, not external instruction.

| Doctrine concept | Strategic Advance mapping |
|---|---|
| Commander’s Intent | Purpose, key tasks, desired end state, and constraints. |
| Mission Command | Give operators and delegates bounded discretion inside shared intent and constraints. |
| Intelligence Preparation of the Battlefield | Define the operating environment, decisive features, intelligence gaps, and collection methods. |
| Common Operational Picture | Maintain current truth in `state.json` and present it through the Strategic Advance board. |
| Protection and Risk Control | Register protected assets, name a concrete threat to each risk, and require guards, stop conditions, recovery, thresholds, and evidence-derived status before risk can redirect the main effort. |
| Main and Supporting Efforts | Commit to one main effort and only the minimum support needed to keep it moving. |
| Decisive, Shaping, and Sustaining Operations | Advance the objective directly, remove blockers, or preserve execution capacity. |
| Decision Points | Use fixed candidate scoring, pre-mutation action gates, and validator-generated active-front pivot predicates with derived receipts. |
| Branches and Sequels | Prepare structured recovery and evidence-backed next transitions. |
| Operational Reach and Culmination | Recompute carrying limits from elapsed time, repeated failures, alternate routes, and policy thresholds. |
| Reserve | Preserve uncommitted context, agent capacity, time, and recovery options. |
| Measures of Performance and Effectiveness | Separate completed activity from a canonical before/after world delta whose semantic effect target is currently satisfied. |
| Commander’s Assessment Cycle | Apply bounded PDCA: predeclare the objective-relative criteria, execute one move, check authoritative effects, then block, monitor, pass, pivot, or preserve gains. |
| Staff and Specialist Review | Dispatch review only under a bounded contract for scope, taxonomy, threshold, evidence bar, budget, and stop condition; one disposition returns to the commander. |
| Consolidation of Gains | Record checkpoints, authoritative readback, structured cleanup debt, and durable evidence. |
