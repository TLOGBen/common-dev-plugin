# 後端架構 — <Spring Boot 分層>

> 分層:**Action → Facade → Service(Domain) → JPA DAO**;對外整合 **mware**;共用元件 **util**;日誌 **log**(AOP + Filter + Logback);安全 **security**(Spring Security + JWT)。
> 對應需求:<單一資料庫、AOP cross-cutting(個資/Logging/Security)、批次、簽核不可 hard-code、稽核軌跡、傳票拋轉、檔案交換、Excel 匯出>。

---

## 一、Package 結構

```
backend/
└── src/main/java/<base package>/
    ├── <App>.java
    ├── common/                         # 全域共用(無業務)
    │   ├── response/                    # ApiResponse{success,data,error,meta}、PageMeta、ApiError
    │   ├── exception/                   # BusinessException、GlobalExceptionHandler(@RestControllerAdvice)、ErrorCode
    │   ├── log/                         # ── log 層 ──
    │   │   ├── LoggingAspect.java       # AOP @Around facade/service:入參出參+耗時
    │   │   ├── RequestLoggingFilter.java# Filter:request/response、traceId、來源 IP
    │   │   ├── AuditAspect.java         # AOP @Auditable → 寫 audit_log(前後值)
    │   │   └── MaskingConverter.java    # Logback 敏感欄位遮罩
    │   └── util/                        # ── util 層(無狀態) ──
    │       └── HttpUtil/FtpUtil/SftpUtil/ExcelUtil/DateUtil/MaskUtil/CryptoUtil/JwtUtil
    ├── security/                        # SecurityConfig、JwtAuthFilter、SsoController/Service、PermissionEvaluator
    ├── mware/                           # 對外:<ehr/accounting/budget/procurement/eip/bank/mail> client
    ├── batch/                           # Spring Batch:config、job/、monitor(BatchMonitorService)
    └── modules/                         # 業務模組(每模組六子 package)
        ├── <module1>/                   # action / facade / service / dao / entity / dto
        ├── <module2>/
        └── …
```

> 每個業務模組固定 `action / facade / service / dao / entity / dto` 六個子 package,職責對齊總覽第二章。

## 二、各層細節

### action(Controller)
```java
@RestController
@RequestMapping("/api/<resources>")
public class <Xxx>Action {
    private final <Xxx>Facade facade;

    @GetMapping
    public ApiResponse<List<<Xxx>DTO>> list(@Valid <Xxx>Query q) {
        return ApiResponse.page(facade.list(q));          // 統一封套 + meta 分頁
    }

    @PostMapping("/{id}/<action>")
    @PreAuthorize("hasRole('<ROLE>')")                    // security 授權
    @Auditable(action = "<ACTION>")                       // log AOP 寫稽核
    public ApiResponse<<Result>DTO> doAction(@PathVariable Long id, @RequestBody @Valid <Xxx>DTO dto) {
        return ApiResponse.ok(facade.doAction(id, dto));
    }
}
```
- 只負責 HTTP I/O、DTO 驗證、權限註解、封套;**不含交易、不碰 DAO**。

### facade(Use-case 編排 + 交易邊界)
```java
@Service
public class <Xxx>Facade {
    @Transactional
    public <Result>DTO doAction(Long id, <Xxx>DTO dto) {
        <Domain> d = <xxx>Service.getEditable(id);
        <xxx>Service.transition(d, Status.PENDING_REVIEW);     // domain 狀態機
        ApprovalInstance inst = approvalService.start("<FORM_TYPE>", id);  // 共用簽核
        mailSender.notifyApprovers(inst);                      // mware
        return assembler.toDTO(inst);
    }
}
```
- `@Transactional` 在此層;組裝多 service 與 mware;**一個 facade 方法 = 一個 use-case**。

### service(Domain)
- 純領域邏輯(<列舉本系統的核心領域計算:租金平準/押金息/出租率/IFRS16/銷帳比對…>);領域模型與規則。
- 不知 HTTP/JSON;不直接做檔案交換(回傳資料,由 facade 交 mware)。

### dao(JPA)
- Spring Data JPA Repository + Entity;複雜查詢 QueryDSL/JPQL;分頁 `Pageable`。
- DB 帳號最小權限(僅 CRUD,無 DDL/Owner);個資欄位加密(`CryptoUtil`)。

### mware(對外)
- 封裝所有外部依賴;統一逾時、重試、斷路(Resilience4j);檔案交換負責目錄管理。
- 對外連線遵規範:固定 Port、用 DNS 不用 IP、SFTP 金鑰管控。

## 三、橫切實作

### log(AOP + Filter + Logback)
- **RequestLoggingFilter**:每請求 `traceId`、方法/路徑/IP/狀態碼/耗時(MDC)。
- **LoggingAspect**(`@Around` 切 facade+service):入參/出參(經 `MaskUtil` 遮罩)、耗時、例外。
- **AuditAspect**(`@Auditable`):寫稽核軌跡——操作、資料異動前後值、權限異動;保留 ≥ <N> 年。
- **Logback**:分環境;檔案 Rotate + 保留期限;敏感欄位 `MaskingConverter`。

### security(Spring Security + JWT)
- 登入走 SSO → `JwtUtil` 簽發 JWT(userId、角色、群組、代理人)。
- **JwtAuthFilter**:每請求驗 JWT、組 Authentication;無狀態 session(STATELESS)。
- 授權:`@PreAuthorize` + 自訂 `PermissionEvaluator`(角色/群組/代理人代理期間繼承)。
- 密鑰/密碼不寫死於程式。

### 例外與回應
- `GlobalExceptionHandler`(`@RestControllerAdvice`)統一捕捉 → `ApiResponse.error(code,msg)`;訊息不洩敏感資料。
- 交易失敗 rollback;異常寫日誌庫。

## 四、批次(Spring Batch)
- Job:<發票批次、押金息計算、介接檔產出、外部同步、銷帳比對、報表批次…>。
- `BatchMonitorService` 提供監控:job 清單/狀態碼/耗時、執行中監看、人工 rerun、失敗 mail/簡訊、批次 log。
- 排程設定不寫死(`/api/batch-schedules`),cron/相依/前後置作業可設定。
