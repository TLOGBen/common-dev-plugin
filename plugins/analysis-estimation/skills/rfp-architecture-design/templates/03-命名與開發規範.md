# 命名與開發規範

> 對應需求:<原始碼要求、架構規範、企業開發規範>。

## 一、命名
| 對象 | 規約 | 範例 |
|---|---|---|
| Java package | 全小寫,`<base>.<module>.<layer>` | `…lease.facade` |
| Class | 層後綴 | `<Xxx>Action/Facade/Service`、`<Xxx>Repository` |
| REST 路徑 | 複數名詞、kebab-case、動作用子路徑動詞 | `/api/lease-contracts/{id}/approvals/submit` |
| DB 表 | snake_case、模組前綴 | `lse_contract`、`tnc_workplace` |
| DTO | `XxxDTO` / `XxxQuery` / `XxxForm` | `<Xxx>DTO` |
| 前端元件 | PascalCase | `AppDataTable.vue` |
| 前端 api | `<resource>.api.ts` | `leaseContract.api.ts` |

## 二、DTO / Entity 規約
- Entity 不外露至 Controller;一律經 assembler 轉 DTO。
- 不可變優先:DTO 用 record / 建構即定型;領域物件以回傳新值而非就地修改。
- 邊界驗證:`@Valid` + Bean Validation 於 action;領域不變式於 service。

## 三、統一回應封套
```jsonc
{ "success": true, "data": {}, "error": null, "meta": { "total": 0, "page": 1, "size": 20 } }
```
失敗:`success=false`、`data=null`、`error={code,message}`,訊息不洩敏感資料。

## 四、個資與安全
- 含個資查詢/報表/匯出後端強制遮罩(`MaskUtil`);解遮罩為獨立授權端點並寫 access trail。
- 機敏資料應用端加密(`CryptoUtil`)後存 DB;金鑰與密碼不寫死(設定檔/Vault),設定檔密碼加密。
- DB/應用帳號最小權限;SQL 參數化(防 Injection);<OWASP Top 10 / WebInspect> 須過。

## 五、例外 / 交易 / 日誌
- `@Transactional` 僅在 facade;失敗 rollback。
- `GlobalExceptionHandler` 統一轉封套;`BusinessException` 帶 `ErrorCode`。
- 所有寫入型操作經 `@Auditable` 寫稽核;敏感欄位入日誌前遮罩。

## 六、設定分環境
- `application-{dev,sit,uat,prod}.yml`;外部連線用 DNS 名稱、固定 Port;機敏設定走環境變數/Vault。
- 交付完整原始碼 + 編譯部署腳本。
