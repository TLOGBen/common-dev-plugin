# 工項與人天分工

主線負責「有哪些工作、為何必須做、選哪條路線、怎樣完成」；定價者負責「這些已定工作需要哪些操作工時、計幾次、如何去重及換算人天」。保持分工可以辨識是範圍擴張，還是單價形成方式造成總額增加；不是把估算責任丟給代理後直接採信。

## 主線交接

交接前核對 SKILL.md 的重大路線條件；有觸發時，清單須帶入使用者的路線決定或明確推薦授權及其限制。仍未決就先交付路線差異與問題，不啟動詳細定價。定價者發現未決選擇被當成已選路線時，回報主線，不代選或用假設定價。

先保存無人天的完整工項清單；每列有穩定 ID、已選路線與實際用法、具體操作及完成標準、共用／批次修改／多點批次修改／獨立例外、計次依據、代表來源位置及必要承重段落、已確認責任與未知。只交版本名稱或「相容調整」不足以定價。既有工程數量可以交付，但標示它是覆蓋證據或實際承作次數。

原封不動帶入已確認的甲方責任、固定額度及排除範圍，包含一次性產物到底只需建置還是要執行。重寫路線帶入逐件清單的路徑與各分級的去重後件數，以及使用者的單價表；定價者只做件數乘單價，不重新分級。對既有清單中的實際 API、頁面或 DAO 修改批次，帶入同類受影響支數及去重／推估依據，由定價者依 rate-card.md 的參考基準換算人天；不為公式新增工項或把檔案數冒充方法數。新框架的固定基礎費及已含能力照原約定。工項清單不含主線臨時猜的單價、歷史總價或欲達到的總額；已約定費率及本手冊基準須完整保留，不能以獨立定價為由隱去。定價者應看見所有工項及其共享歸屬，不逐列隔離估價。

## 獨立定價

開一個新上下文定價 subagent，明確不繼承主線歷史（支援 fork_turns 的載體用 none）。使用者指定模型或 profile 優先；未指定時用載體目前可用、適合獨立計算的模型，回覆中寫明實際用了哪一個。若無法委派，如實記錄退化模式，由主線按同一工項估算並交付，不假稱獨立定價通過、不因載體卡住初估。

主線用下列固定任務內文派工，只代換實際檔案／目錄路徑並附上使用者新增的責任限制與約定費率。計價方法由原手冊傳給定價者，不另寫一份公式摘要；摘要若漏掉加值的原始工時或取整順序，定價者即使照單執行也會失真。

> 你負責已定工項的獨立定價。先完整讀 `<Skill目錄>/references/granularity.md` 與 `<Skill目錄>/references/rate-card.md`，再讀 `<無人天工項清單路徑>`；依兩份手冊原文計算，不以本訊息取代手冊。來源只限清單直接列出的代表證據。逐件清單已分級的工作用 rate-card.md 的逐件分級單價，件數與分級照清單、單價照使用者給的表，不重新分級；其餘沿用操作工時法；同框架的實際修改批次先估在同類 N₀ 支參考規模的基準工時，再以 N / N₀ 線性換算、最後四捨五入，只改人天產出。固定框架費、共用一次及獨立例外不放大，同一件工作不同時走逐件單價與批次換算。依 rate-card.md 的操作輸入流程保存 JSON，執行附帶工具，在 `<定價產物目錄>` 產生同一 ID 的原始輸入、計算結果及定價表。有量級缺口回報原 ID 及最多三個具體問題。只寫該定價輸入與工具產物，不改產品、不另派代理、不重選路線或擴張範圍，不重跑全庫盤點／網路研究，也不要求主線先算價。

- 先依 granularity.md 核對同一規則能否重用；多點批次修改拆出同質小批及剩餘逐點操作，不把同一次施工視為同質。先統一共享工作歸屬，再形成每列 E／V 操作。批次基準指參考支數下的一批工作，不能已乘本案數量再縮放第二次；分清不縮放的共用操作，沿用已定驗證涵蓋。保留基準工時、N₀、N、倍率與四捨五入前後值；約定費率換算明示來源，其餘不能把預猜整包天數乘 8 倒填。
- 普通除錯、既知必要改造與語意驗證是基準。只有基準未涵蓋且具體的剩餘工作才另算低高中點；同根因與甲方已承擔工作不加。
- 依 rate-card.md 用工具計算，保留每列原始步驟、工時、次數、B、A、固定額度及去重。B 與 A 的 E／V 分別取整後，才比較同工項累計 A ≤ B/5；不可改成先加原始 B/A 小時再一起取整，也不可用未取整的 A 通過門檻。超額回查漏列、重複或重大異動，不能直接截價／膨脹B。
- 若一個工項仍缺會改變量級的操作／次數／責任，回傳原 ID 與具體缺口，保留有依據的假設或標待估；不以泛用緩衝代替未知，也不自行增列一整包工作。可拆操作明細，但改工項或路線交回主線。

## 回傳及接續

回傳同一 ID 的人天主表、可重算的 E／V 操作與次數、一般加值及分類、固定額度、共享工作歸屬，以及最多三個需要主線處理的重大缺口。以同一版本目錄的 input.json、result.json、pricing.md 回傳，不另手算或重抄另一份內部價格表；不用另產報告圖或完整客戶文案。

主線以工具對帳行合計、原工時到人天、A的取整與20%、固定額度及共享歸屬。若發現問題，一次集中補事實／指出受影響 ID，至多讓同一定價者修正一輪；只重算受影響部分。仍無法定價的必要工作明列待估，交付可討論的小計，不讓問答演變成完整重新研究。主線不能為了看起來合理自行縮放總額或改另一套價。

接受後沿用同一數列產生主表與明細，再進入 pm-delivery.md 的 writer 與主線檔案核對。Writer 整理文字，主線確認實際報告忠實引用已接受的資料與條件。有新證據指出價格問題時沿用本節修正邊界，不因撰文或交付核對重開修正額度，也不藉補寫說明追加施工。
