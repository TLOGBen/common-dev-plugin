# 可選接手便箋：先證明有用，再考慮加入 skill

自身 dogfood 顯示帳本會留有落後的 focus，且每次 CLI 回傳整份狀態（包括事件歷史）。讀回 JSON 對機器合理，卻不是人接手的最佳第一層。這不證明 Astra 不能自行摘要，也不代表需要每一步增加 render。

候選只加一個只讀 campaign_brief.py，從同一帳本及證據完整性產生 Markdown：目標、紀錄狀態、目前主攻、未達條件、未結操作、已記錄成果與證據入口。不新增 state 欄位、不重排序工作優先權、不代人作決定、不把條件比例轉成整體完成百分比。已完成 focus 會明示需重新判斷，不自動選下一個 ID。證據缺失／改變不隱藏成綠燈；語義仍由主手判斷。

採用門檻：機械控制保留所有必要限制、現有工件不變、新檔不覆蓋；實際模型讀者能分清已記錄達成／整體尚未完成、已核准／已投用、未知操作與下一步。原始 JSON 也正確可用時不宣稱模型必需此工具；看的是接手資訊取得成本與有沒有漏掉重要脈絡。提供同樣完整性資訊，避免把額外觀測能力誤叫純排版改善。

先在 experiments/common-lab-candidate018/source/common-lab/ 做未採用候選。既有.7 source、exports、正在跑的resume fixtures不動。若採用，只從 conditional campaign reference 路由，root SKILL不加必跑呈現規則。此工具不自動開檔或發布；人不在也不製造教學小考。
