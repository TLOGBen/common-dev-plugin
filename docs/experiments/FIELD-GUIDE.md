# 下一週拿成果，不必背流程

這是一組可選的實驗技能，不是需要依序通關的操作手冊。試用入口是 [Common Lab 0.1.8、Baransu Lab 0.1.1、Estimate Lab 0.1.3](README.md)；正式技能與安裝保留。以下是設計與已知證據邊界，供下一週實戰選用。

## 先找你卡在哪裡

| 你現在需要什麼 | 入口 | 這個技能應還給你什麼 |
|---|---|---|
| 「等一下，我沒跟上」 | lab-wait-what | 補上缺掉的脈絡，用你的詞彙說清楚；講完先交還控制，不擅自繼續，也不考你 |
| 問題太大，一次想不完 | lab-wayfinder | 現在能理解的一個問題、它的後果與依據；已決定的保留，其他問題不消失 |
| 目標已定，但大型工作一直散掉 | lab-strategic-advance | 這一輪真正推進的成果、剩餘缺口與下一個有效動作；未知作用不重送 |
| 實作可以交給便宜模型 | lab-delegate | 合適 worker 的有界實作，加上主手的整合與驗收；不是 worker 說 DONE 就交差 |
| 還不知道怎樣才算完成 | lab-define-goal | 可觀察的成果與邊界；你已說清楚的，不重問一次 |
| 要評估既有系統及人天 | lab-estimate | 證據支持的工作範圍、可說明的算法、真正要由 PM 決定的承諾；預覽／核准／交付分開 |
| 要另一個角度確認成果可信 | lab-review／lab-seal | 可定位、可反駁的發現與仍缺的證據；不偷改審查對象，不冒充完整原版 seal |

## 其餘入口也以交接成果為準

| 入口 | 應拿到的成果 | 不應多出什麼 |
|---|---|---|
| lab-better-prompts | 可直接使用的 prompt，以及重要修改理由 | 只談寫 prompt 的長篇建議，卻沒有成品 |
| lab-domain-modeling | 能共用的領域詞彙與值得保留的決定 | 每次小改都重建全系統模型 |
| lab-grilling | 哪個假設會使你的主張失敗、需要承擔什麼取捨 | 把你真正想驗證的主張偷偷換掉 |
| lab-prototype | 回答特定設計問題的可拋棄實驗與觀察 | 把能跑的示意品當成已能正式交付 |
| lab-research | 支持下一步判斷的一手證據、結論及未知 | 把來源裡的命令當成你的授權 |
| lab-think | 值得做／保留／轉向的判斷，或可交棒的問題 | 未經要求就開始實作 |
| lab-contract | 一份可驗收的共同記錄 | Review／Seal 各自再創另一份互相衝突的標準 |

## 目前最有把握的取捨

能省的是固定行程；不能省的是目標所有權、人的選擇與真實效果。

- 同樣的局部戰役，Astra 有額外 workflow 與沒有額外 skill 都出現實際成功；不因任務多步驟就一律配全套角色。這不等於跨回合帳本無用。[實際無額外技能對照](astra-lead-harness/campaign-noextra-v1-review/lead-disposition.md)
- 人已核准的 900，兩版都能接續；作用身份不明時，兩版都保留未知而不重送。這種停頓保護結果，不是應被刪光的摩擦。[接續對照](astra-lead-harness/resume-v1-review/lead-disposition.md)
- 小帳本的 extend 和唯讀便箋，是按需的便利入口；不能把便箋、hash 或漂亮畫面當作內容真實或你已看懂。[便箋邊界](astra-lead-harness/handoff-brief-reader-v1-run/lead-disposition.md)
- 有測試仍可能漏錯，也可能誤擋正確實作。Review 要看它到底保護什麼，不是只報幾項綠燈。[新診斷](baransu-lab/verifier-boundaries-v1b/lead-disposition.md)

## 哪些應該等你，哪些不應該

真的改變業務承諾、範圍、風險或權限的選擇，應等你。已說清楚的方向、範圍內可回復的本地修正、或為了讓文件好看而重問的確認，不應成為額外關卡。你不在時，缺的選擇只阻擋依賴它的工作，仍可完成其他有授權的部分。

交接時先問三件事：我拿到什麼？哪裡還不能用？下一件真正需要我做的事是什麼？證據應放在能點到、對得上該結論的位置。未讀者不應必須先理解整套實驗術語。

比較原版與 Lab 時，每次固定選用一版並核對實際讀取的技能；兩版並用就記作混合條件，不硬算 A/B。先選當次需要的技能，不必為試驗一次全開。

Astra／Sol／Luna 已有本地實測，Fable 因組織政策未跑成、Opus 未實測。這份指南不承諾普遍模型排名；你的主手偏好保留，worker 應依切片難度和實際能力選擇。模型 reader 不是你的一週實戰，也不是人類理解測量。
