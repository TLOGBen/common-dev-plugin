Type: grilling
Status: resolved

## Question

客服名單應預設顯示全名還是遮蔽姓名？這是隱私與辨識便利的取捨，必須由使用者決定。

## Evidence

## Options

- 全名：辨識較直接，但同屏曝光較多資訊。
- 遮蔽姓名：降低名單曝光；必要辨識仍須沿用既有授權流程。

## Recommendation

原建議偏向遮蔽姓名；使用者已明確選擇此方案，決定記錄於 Answer。

使用者本回合明確決定：「遮蔽姓名」。客服名單預設採用遮蔽姓名；不再等待使用者回答同一選擇。必要辨識仍沿用既有授權流程，現有登入與權限不變。

本票解決的是姓名呈現取捨，並不代表票 24 的產品程式已實作或取得本回合實作授權。
