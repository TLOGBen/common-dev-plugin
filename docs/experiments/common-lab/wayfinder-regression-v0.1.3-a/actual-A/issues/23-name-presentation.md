# 名單姓名呈現

Type: grilling
Status: resolved

## Question

客服名單應預設顯示全名還是遮蔽姓名？這是隱私與辨識便利的取捨，必須由使用者決定。

## Evidence

目前產品使用全名；現有權限不因本票自動改變。

## Options

- 全名：辨識較直接，但同屏曝光較多資訊。
- 遮蔽姓名：降低名單曝光；必要辨識仍須沿用既有授權流程。

## Recommendation

偏向遮蔽姓名，但這不是已取得的人類同意。

## Comments

上回停在等待使用者選擇；尚未寫入答案。

本回合使用者已明確回答「遮蔽姓名」，以上等待紀錄保留作為歷史；不再等待或重問同一選擇。

## Answer

使用者決定：客服名單預設採用遮蔽姓名。此為使用者親自給定的答案，並非代理人代選。

必要辨識沿用既有授權流程，現有登入與權限不變。本票完成的是姓名呈現決策；[產品畫面實作](24-implement-view.md) 尚未執行，亦不在本回合授權範圍。
