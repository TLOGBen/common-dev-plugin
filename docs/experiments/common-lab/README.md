# Common Lab 0.1.8

> 歷史版本說明。Git 已不再保留這份舊套件；目前請依[試用入口](../README.md)安裝 0.2.0。以下版本、路徑及結果只對應原批次，重測方式見試用入口末段。

Common 的 10 個獨立實驗技能。保留各技能解決的問題，移除必須照固定旅程走完的要求；不是只把原文刪短。

| 入口 | 要還給人的結果 |
|---|---|
| `lab-define-goal` | 能驗收的目標、邊界與停止條件；已清楚的決定不再問 |
| `lab-delegate` | 更合適的 worker 完成實作切片，主線仍對整體目標負責 |
| `lab-wayfinder` | 一次能理解的當前問題，並保留已解決與未解決的完整脈絡 |
| `lab-strategic-advance` | 依可查證的成果推進長程目標，工具成功不冒充目標完成 |
| `lab-wait-what` | 補齊眼前缺少的脈絡、用白話說清楚；不把解釋變成小考 |
| `lab-better-prompts` | 可直接使用的 prompt 與必要的修改理由 |
| `lab-domain-modeling` | 能共用的領域語言與值得保留的決策 |
| `lab-grilling` | 真正會使想法失敗的假設，以及需要人決定的取捨 |
| `lab-prototype` | 回答具體設計問題的可拋棄實驗，不冒充正式產品 |
| `lab-research` | 有一手來源支持、可用於下一步判斷的研究結果 |

## 使用

安裝步驟與實戰記錄方式見[共同入口](../README.md)。最新已驗證 Codex 包為 `experiments/common-lab-v0.1.8/`；例如 `$lab-wayfinder`、`$lab-delegate`。原版名稱與安裝保留。

0.1.3 目前主要變更是 Wayfinder：先顯示當前焦點，完整地圖按需展開；依賴已就緒只叫「前置就緒」，不表示產品完成或已獲執行授權。未知票券狀態會拒絕產生看似正常的地圖。

0.1.5 修正 Grilling 的批判對象：可以挑戰有問題的方法，但不能悄悄替換使用者已明確提出、真正想測的主張。0.1.4 曾過度保護原方法而失敗，未導出；保留失敗樣本。0.1.5 的 8 次固定回歸有改善證據，不宣稱全情境勝出。

0.1.7 補上戰役途中追加必要成果的 `extend` 工具；舊成果、歷史與未知操作保留，不增加根技能必讀規則。[四次 Astra 主手對照](../astra-lead-harness/extension-v1-review/lead-disposition.md)中基線也全數成功，採用的是受測入口的便利性，不是宣稱模型需要更多管束。0.1.6 Delegate 單條候選未證明增益，未採用。

0.1.8 增加按需的唯讀交接便箋，幫人找到目標、當前焦點、可查證結果和未決操作；它不修改帳本、不推定下一步、不拿 hash 正確冒充內容正確。[四次 reader proxy](../astra-lead-harness/handoff-brief-reader-v1-run/lead-disposition.md)支持窄幅採用此入口，但兩版都回讀原始資料，不宣稱省讀量或真人理解已改善。

## 驗證與限制

- 76 項 renderer 回歸通過；實際瀏覽器檢查了內容、鍵盤與狀態呈現。沒有像素截圖或真人理解的完成宣稱。
- 原版／Lab 有分輪同情境比較及實際工件操作，詳[發現與限制](RESULTS.md)。不同版本的結果不能混成一個新版勝率。
- 本地隔離安裝與位元一致性已通過；沒有宣稱已替使用者的另一個 App／Host 升級。

[原始實驗設計](RUN.md)保留初輪的模型、版本与判準。後续重測使用各批次自己的凍結設計；舊設計的「尚未測」描述只代表當時，不覆寫歷史。
