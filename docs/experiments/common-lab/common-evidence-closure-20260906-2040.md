# Common：已修正的問題與人能接手的部分

這份核對支持 C2／C3 的有界實驗要求，不是整場結束或真人試用通過。主線重新核对 12 個證據入口；Wayfinder 四個目前分發來源與 0.1.3 受測 bytes 相同。[核對紀錄](common-evidence-closure-20260906-2040.json)保留 hash、範圍與限制。

| 你會拿到什麼 | 目前能支持到哪裡 | 仍不能宣稱 |
|---|---|---|
| 保留你的原意及真正護欄 | Prompt 不把可重建變成刪除許可；Prototype 保留既成扣款；Strategic 不把一次成功當唯一性；Grilling 不偷換你要測的主張 | 少量情境不能保證全域正確，也不是新版全面勝出 |
| 一次可理解的當前問題 | Wayfinder 真的保留已回答決定、產生新地圖，使用者離席不阻止獨立查核；「前置就緒」不再暗示獲准實作 | 地圖存在／可操作不等於人已理解或同意 |
| 可接手的成果與缺口 | Wait What、Wayfinder、Strategic 回答與 reader 有對應證據；實際驗收能拒收假綠燈與不適用收據；便箋提供按需入口 | reader 回述不是你的使用感受；簡短、模型高分與綠燈數不是品質百分比 |

[固定與新增反例](runs/astra-r2-011/manual-review.json)、[Grilling 採用判斷](grilling-claim-heldout-015-a/lead-acceptance.md)、[實物交接](runs/astra-execution-012/lead-acceptance.md)、[讀者限制](runs/reader-astra011-sol-01/lead-review.md)、[瀏覽器核對](wayfinder-browser-qa-v0.1.3.md)各自保留，不合成一個看似完整的勝率。

我們自己的機械便箋也還有摩擦：英語驗收原文及重複證據入口，不利於初次閱讀。解法是主手整理繁中交接與精準入口，不讓 renderer 擅自改寫驗收原意。下一週試用先從[成果入口指南](../FIELD-GUIDE.md)選當下需要的技能，不必走完整套流程。
