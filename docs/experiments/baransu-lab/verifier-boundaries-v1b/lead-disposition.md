主線已讀四 final、全部關鍵命令與反例輸出；重複原碼dump不重讀。R4 的 6,220／1,555 指枚舉輸入與 limit 組合，不是 7,775 項測試函式；計數從其迴圈和真输出核對。R1有3次引號換行 SyntaxError，最後以有效 -c 修復；部分 command aggregate 空白，不能說沒執行。heredoc被拒只有actor自述，未在本raw追到獨立toolitem。未觀察target寫入／ops CLI／網路／delegation；各輸入hash不變，不能因此推論完整OS存取日誌。
