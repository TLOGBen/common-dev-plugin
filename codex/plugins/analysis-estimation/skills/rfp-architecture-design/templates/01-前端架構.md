# 前端架構 — <Vue 3 + Vite + Sass + Vuetify>

> 標準結構;對應需求:<Web Based、跨瀏覽器、SSO 登入、角色化選單、個資遮罩呈現、報表/Excel 匯出、視覺化分析、線上簽核 UI>。

---

## 一、技術選型

| 項目 | 選用 | 說明 |
|---|---|---|
| 框架 | <Vue 3(Composition API + `<script setup>`)> | 一級框架 |
| 建置 | <Vite> | 快速 HMR |
| UI 元件庫 | <Vuetify 3> | 表格/表單/對話框/日期 |
| 樣式 | <Sass(SCSS)> | 自訂 theme、共用變數 |
| 狀態管理 | <Pinia> | 模組化 store(權限/使用者/主檔快取) |
| 路由 | <Vue Router> | 角色化動態路由 + 權限守衛 |
| HTTP | <Axios(apiClient)> | 攔截器掛 JWT、統一封套解析、錯誤處理 |
| 圖表 | <ECharts> | 分析視覺化 |
| i18n | <vue-i18n> | 繁體中文為主 |

## 二、目錄結構

```
frontend/
├── vite.config.ts                 # proxy /api → 後端、build
├── package.json
└── src/
    ├── main.ts                     # createApp + UI + 狀態 + Router
    ├── plugins/                    # vuetify.ts、axios.ts(JWT/封套/errorHandler)
    ├── styles/                     # settings.scss(theme 覆寫)、_variables.scss
    ├── router/                     # index.ts(beforeEach 權限守衛)、routes/(依模組)
    ├── stores/                     # auth/menu/<module>
    ├── api/                        # 對應後端端點薄封裝(<resource>.api.ts、approval.api.ts、report.api.ts、audit.api.ts)
    ├── types/                      # api.ts(ApiResponse<T>)、<module>.ts
    ├── composables/                # usePagination/useApproval/useExport/useMask
    ├── components/                 # common(AppDataTable/SearchPanel/ConfirmDialog/FileUpload)、approval、charts
    ├── layouts/                    # DefaultLayout(角色化側選單+公告彈窗)、BlankLayout
    └── views/                      # 依模組對應 <N> 功能(各業務模組 + admin + ops)
```

## 三、頁面 ↔ 功能對應(頁型樣板)

| 頁型 | 共用元件 | 對應頁面操作 |
|---|---|---|
| **列表頁** | `SearchPanel` + `AppDataTable` + `usePagination` | 查詢列表、過濾、分頁、進明細、匯出 |
| **明細/編輯頁** | Vuetify Form + rules | 查詢明細、新增/編輯、暫存、上傳附件、即時檢核 |
| **簽核頁** | `ApprovalActions` + `ApprovalFlowViewer` | 送簽、撤銷、進度追蹤、退件通知、異動紅字 diff |
| **批次/報表頁** | `useExport` + 進度條 | 批次產生、輪詢 jobId、下載 |
| **儀表板頁** | `charts/*` | 視覺化、一鍵撈出、多維切換 |

## 四、安全與權限(前端側)

- **登入**:導向 SSO,callback 取 JWT;`auth` store 保存使用者/角色/群組/代理人權限。
- **Axios 攔截器**:request 掛 `Authorization: Bearer`;response 解 `data.data`,401 導回登入,403 提示無權限。
- **路由守衛**:`beforeEach` 依角色判斷可進頁面;選單依角色動態渲染。
- **個資遮罩**:後端已遮罩,前端僅呈現;解遮罩 `useMask().reveal()` 帶事由呼叫(後端寫 access trail);稽核角色全唯讀。
- **公告/停機**:`DefaultLayout` 載入時取 active 公告彈窗。

## 五、建置與相容

- `vite.config.ts` 設 proxy 將 `/api` 轉後端;build 產靜態檔。
- Browserslist 鎖定指定瀏覽器版本確保編譯目標相容。
- Sass 變數集中覆寫 theme,不在元件散寫色碼。
